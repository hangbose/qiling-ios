# App Icon

Production iOS app icon, exact square 1024x1024, opaque. Use the attached original indigo fox-kitten as character identity reference: amber eyes, gold crescent forehead, bright blue inner ears, cream muzzle. Frame head and upper chest only, playful friendly expression, crisp polished creature RPG illustration. Simplify tiny fur details for legibility at small sizes. Full-bleed pale ivory/mint gradient background. No text, no border, no rounded-corner mask, no transparency, no mockup. Keep both ears inside safe margins.
