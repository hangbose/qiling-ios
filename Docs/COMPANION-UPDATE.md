# 陪伴体验更新

本轮改动继续保持健康数据自动结算，不要求手动领取或补打卡。

- 首页点击宠物：弹跳、轻触反馈和四条轮换回应；遵循减弱动态效果设置。互动不奖励积分。
- 健康同步增加经验：显示本次成长、升级或进化反馈；确认后持久保存已读经验。升级门槛保持每 100 XP，进化保持 1000 / 3000 XP。
- 首页连续达标：任一目标达标即计一天；今天尚未达标时从昨天计算，不提前中断。
- 成长页日历：翻月、选择日期、查看该日实际数据和当时目标；没有数据不会显示为失败。
- 首页“晒晒伙伴”：生成可分享图片，包含伙伴、等级、周积分；不包含健康明细，演示模式有明确标记。

## 真机验收

1. 演示模式点按宠物，确认回应与动作，打开减弱动态效果后确认无额外跳动。
2. 成长页打开日历，切换月份与日期，检查历史记录、空日期、未来日期。
3. 首页向下滚动，分享成长卡片到系统分享面板。
4. 真实健康同步达到目标后确认经验自动增加，关闭提示后再次同步不能重复弹出；跨过 1000 / 3000 XP 时显示新形态。

源码更新和模拟器检查不代表 TestFlight 已更新；需要另行签名上传新构建。Apple 安装分发支持工单独立处理。
